## 🚀 Featured Projects

### 📈 Global Agricultural Production → Exploratory Data Analysis
**Cleans a messy real-world FAOSTAT dataset (1961–2024) and answers 7 questions about what the world produces, who produces it and how it has changed.**

![Python](https://img.shields.io/badge/PYTHON-3776AB?style=flat-square&logo=python&logoColor=white)
![Pandas](https://img.shields.io/badge/PANDAS-150458?style=flat-square&logo=pandas&logoColor=white)
![Matplotlib](https://img.shields.io/badge/MATPLOTLIB-11557c?style=flat-square)
![FAOSTAT](https://img.shields.io/badge/DATA-FAOSTAT-00e676?style=flat-square&labelColor=0d1117)

- 🧹 Removed aggregate rows and non-country entries (like "World") using UN M49 area codes
- 🔍 Traced the 2024 production dip to incomplete reporting, not a real collapse
- 📊 Found that the top 10 products make up about 59.5% of recorded production

📂 [Repository](https://github.com/Tanisha-yadav-11/Agricultural-EDA-project)
